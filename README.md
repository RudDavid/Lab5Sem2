# Lab5Sem2 version1.1

Данная программа представляет собой проверку старых навыков работы с файлами и новых с коллекциями и строками.
Здесь реализован мини-словарь из неправильных слов и их исправленных версий(Dictionary<string, string>), простая программа замены ошибочных слов, путь к папке с файлами программа получает от пользователя и читает только файлы формата .txt.
Также здесь представлена работа с регулярными выражениями и простая замена телефонного номера на прописанный в программе.
